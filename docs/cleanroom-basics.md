# Cleanroom Basics — What I Learned

## Why a cleanroom?

MEMS fabrication involves very small features and thin layers. Contamination from dust, skin oils, fibers, chemicals, and cross-process residue can spoil lithographic patterns or film adhesion. Cleanroom procedures reduce this risk; they do not eliminate it completely.

## Preparation described in the source lab summary

The course summary describes hand washing, changing into cleanroom clothing, using gloves, shoe covers, and hair covering, followed by air-shower access. These steps reflect **the reported local orientation**, not a universal dress code for every cleanroom. Actual required garments and entry procedures depend on local cleanroom classification and facility policy.

## Why this matters across multiple tools

- **Before coating:** Surface residues can cause film defects and poor adhesion.
- **Before deposition:** Particles and contamination can affect deposited film quality.
- **Before lithography:** Contamination can distort features or cause local defects.
- **Across tools:** Tool-specific rules help control cross-contamination between materials.

> This page is theoretical orientation. It is not a substitute for certified cleanroom training.
